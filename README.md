Repositório oficial do website institucional e portfólio de **Leo da Silva** — Designer Digital, Gestor de Tráfego Pago (Meta Ads & Google Ads) e Estrategista de Redes Sociais sediado em Luanda, Angola.

O projeto foi construído para apresentar serviços de alto impacto, estudos de caso detalhados, cases de sucesso e captar novos clientes através de interfaces modernas, responsivas e de alta performance.

---

## 🚀 Tecnologias e Ferramentas

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Biblioteca UI:** [React 19](https://react.dev/)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Componentes:** [shadcn/ui](https://ui.shadcn.com/) & Base UI
- **Ícones:** [Lucide React](https://lucide.dev/)
- **Métricas & Analytics:** Vercel Analytics e Google Analytics
- **Gerenciador de Pacotes:** [pnpm](https://pnpm.io/)

## 🛠️ Como Executar Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) (versão 18+ recomendada)
- [pnpm](https://pnpm.io/) (ou `npm` / `yarn`)

### 1. Clonar o repositório
```bash
git clone https://github.com/SEU-USUARIO/leodasilva-portfolio.git
cd leodasilva-portfolio
```

### 2. Instalar as dependências
```bash
pnpm install
# ou
npm install
```

### 3. Iniciar o servidor de desenvolvimento
```bash
pnpm dev
# ou
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para visualizar a aplicação.

## 📦 Scripts Disponíveis

| Comando | Descrição |
|---|---|
| `pnpm dev` | Inicia o servidor local em modo de desenvolvimento |
| `pnpm build` | Cria a versão de produção otimizada da aplicação |
| `pnpm start` | Inicia o servidor com o build de produção |

## 🌐 Deploy

O projeto é otimizado para deploy na plataforma [Vercel](https://vercel.com/):

1. Conecte o repositório na Vercel.
2. As configurações de build padrão do Next.js serão detectadas automaticamente.
3. Configure as variáveis de ambiente necessárias (como IDs do Google Analytics, se aplicável).
